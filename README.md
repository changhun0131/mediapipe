# Mediapipe Face Detection Project

이 프로젝트는 Mediapipe 라이브러리를 사용하여 얼굴 인식을 구현한 프로젝트입니다.

## 프로젝트 설명

이 프로젝트는 Python과 Mediapipe 라이브러리를 사용하여 실시간 얼굴 인식을 구현하는 것을 목표로 합니다. 
OpenCV를 통해 웹캠을 이용한 얼굴 인식뿐만 아니라, 주어진 `.mp4` 파일을 통해 얼굴을 인식할 수 있습니다.

## 설치 방법

1. **환경 설정**:
   - 먼저 Python 3.x를 설치하세요.
   - 가상 환경을 설정하려면 다음 명령어를 실행하세요.

     ```bash
     python -m venv .venv
     ```

2. **필요한 라이브러리 설치**:
   - 가상 환경을 활성화한 후, 필요한 라이브러리를 설치합니다.

     ```bash
     pip install -r requirements.txt
     ```

3. **파일 실행**:
   - 얼굴 인식을 실행하려면 아래 명령어를 사용하세요.

     ```bash
     python face_detector.py
     ```

   - `face.mp4` 파일을 사용하여 얼굴 인식을 실행하려면, `face.mp4` 파일 경로를 지정하여 실행합니다.

## 사용법

1. **웹캠을 이용한 실시간 얼굴 인식**:
   - 카메라를 연결하고 프로그램을 실행하면 실시간으로 얼굴을 인식합니다.

2. **`face.mp4` 파일을 이용한 얼굴 인식**:
   - `.mp4` 파일을 제공하여, 파일 내의 얼굴을 인식할 수 있습니다.

## 요구 사항

- Python 3.x
- mediapipe
- opencv-python
- 기타 라이브러리는 `requirements.txt`에 명시되어 있습니다.
